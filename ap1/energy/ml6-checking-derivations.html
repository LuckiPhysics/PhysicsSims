Checking Derivations

About 15 minutes · Optional · Works for every unit, not just Energy

AP free-response questions often say "derive an expression" and then "is your answer reasonable? Justify." This lesson gives you three quick tests that check a symbolic answer without redoing the algebra: units, limiting cases, and direction of change. Then you'll practice writing the justification.

Have your notes sheet out. When you see an orange Notes · Box A tag, fill in that box on your sheet. The diagrams are already drawn, so you only write the key ideas.

Tap Start when you're ready.

Notes · Box A

Test 1: Do the units work?

A ball is dropped from rest from a height h. Four students give an answer for its speed at the ground. A speed must come out in m/s. Tap each one to check its units (h in m, g in m/s²).

Check all four. (Next unlocks once you do.)

Box A: Replace each symbol with its units and simplify. Both sides of the equation must match.
• Handy units: N = kg·m/s², J = kg·m²/s², k in N/m = kg/s², μ and angles have no units.
• Wrong units → the answer is definitely wrong (2gh, √(2h/g)).
• Right units → it might be right. √(gh) passes but is missing the 2. Units can't catch missing numbers or unitless factors like μ.

Box B: Limiting case: let one variable → 0 or → ∞. First predict from the physics what should happen, then see what the expression does. They must agree.
• μ → 0 (no friction): the block should slide forever, d → ∞. Ana's gives ∞ ✓. Ben's gives 0 ✗, so Ben is wrong.
• Ben's units are fine (μ has no units), so only the limiting case caught his mistake.
• Pick limits you can picture: no friction, a huge mass, no spring.
Notes · Box C

Test 3: Which way should it change?

The same spring launches a ball of mass m on a frictionless floor. Kai derives its launch speed:

v = x√(k/m)

For each change, decide from the physics whether the speed should go up or down. Then see if Kai's expression agrees.

A stiffer spring (bigger k)
A heavier ball (bigger m)
Squeeze the spring farther (bigger x)

Answer all three. (Next unlocks once you do.)

Box C: Direction of change: if a variable goes up, should the answer go up or down? A variable in the numerator makes the answer grow; in the denominator, shrink.
• Kai's v = x√(k/m) passes all three: bigger k → faster, bigger m → slower, bigger x → faster.
• Going further: how much? Double x → double v (v ∝ x). Double k → v only grows by √2.
Notes · Box D

Writing "reasonable" on an FRQ

A full justification has two halves: what the physics says should happen, and what your expression does. Use this frame:

"Consider [the limit or change]. Physically, [what should happen] because [reason]. My expression gives [what it does], so it [is / is not] reasonable."

Try it. Which is the best justification that Ana's d = kx²/(2μmg) is reasonable?

Box D: A "reasonable" justification needs both: (1) the physics prediction with a reason, and (2) what the expression does in that case. One limit that agrees is enough unless the question asks for more. One limit that disagrees proves the expression is wrong.
Notes · Box E

Worked example: R4's water slide

In R4 you derived the speed at the bottom of a water slide (drop h, length L, friction force f, starting speed vi). Is it reasonable?

vf = √(vi² + 2gh − 2fL/m)
Step 1: Units. vi² and gh are m²/s². fL/m is N·m/kg = (kg·m/s²)(m)/kg = m²/s². Every term under the root matches, and √(m²/s²) = m/s ✓.
Step 2: Limiting case f → 0. With no friction we expect the frictionless answer. The expression becomes √(vi² + 2gh), which is exactly what mgh + ½mvi² = ½mvf² gives ✓.
Step 3: Direction, longer slide. A longer slide means friction acts over more distance, so vf should go down. L is in a subtracted term, so bigger L → smaller vf ✓.
Step 4: Limiting case m → ∞. With the same friction force, a very heavy rider should barely be slowed. The fL/m term → 0, leaving the frictionless answer ✓.
Step 5: Write it up.
"Consider f → 0. Physically, with no friction the rider should reach the frictionless speed, √(vi² + 2gh), because all of Ug becomes K. My expression gives √(vi² + 2gh) when f = 0, so it is reasonable."
Box E: Units: every term is m²/s² ✓. f → 0 gives √(vi² + 2gh) ✓. Bigger L → smaller vf ✓. m → ∞ → frictionless answer ✓. Going further: if 2fL/m is bigger than vi² + 2gh, the root has no answer: the rider stops before the bottom.

Before you go

Check that Boxes A–F on your notes sheet are filled in, then write the big idea at the bottom in your own words.

  • Units: wrong units → definitely wrong. Right units → maybe right.
  • Limiting cases: push one variable → 0 or → ∞, predict from physics, compare.
  • Direction: if a variable goes up, should the answer go up or down?
  • Write both halves: what physics predicts (and why) + what the expression does.

These tests work in every unit. Come back to this lesson whenever an FRQ asks if an answer is reasonable.
