Conservation with Friction

About 15 minutes · Review for the Energy reassessment

R1–R3 gave you the energy forms and the work that moves energy in or out. This lesson puts them together: which forces can store energy, how friction takes energy out of a system, and how to solve a problem with several stages.

Notes · Box A

Does the path matter?

A 2.0 kg box is moved from point 1 down to point 2, which is 3.0 m lower. Friction on it is 4.0 N along whatever path it takes. Tap a path and compare the work done by gravity and by friction.

Distance traveled
Work by gravity
Work by friction

Try both paths. (Next unlocks once you do.)

Box A: A conservative force (gravity, a spring) does work that depends only on the start and end points, not the path. Around a closed path (back to the start) its work is zero. That's why it has a stored energy, U.
A nonconservative force (friction, air resistance) does work that depends on the path: a longer path means more negative work, and a round trip doesn't cancel. It has no U.
Notes · Box B

Friction takes energy out of the system

Now the box slides from rest at point 1 down to point 2. Choose the box + Earth as the system. Friction comes from the surface, which is outside the system, so it does external work:

Ki + Ui + Wext = Kf + Uf

with Wfriction = −fd, where d is the distance traveled along the path

Try it. Without looking at the chart: on the curvy path, what is the box's K at point 2?

Box B: ΔEsys = Wext, or Ki + Ui + Wext = Kf + Uf.
• Friction from outside the system does W = −fd, with d the path length. It takes energy out.
• Straight ramp: 58.8 J − 20 J = 38.8 J of K. Curvy path: 58.8 J − 30 J = 28.8 J.
• No external work (Wext = 0)? Then K + U stays constant.

Box C: For a problem with stages, label the moments (a, b, c) on the diagram and list the energy at each one.
• a: Us = ½(400)(0.20)² = 8.0 J.   b: K = 8.0 J (no friction yet).
• b → c: 8.0 J − (1.5 N)(1.4 m) = Ug + K → 8.0 − 2.1 = 4.9 + K, so Kc = 1.0 J and vc = 2.0 m/s.
• You can skip b and go straight from a to c. Count friction only where it acts.
Notes · Box D

Worked example

A rider of mass m starts down a water slide at speed vi. The bottom is a height h lower, and the slide is L long. The water and slide exert an average friction force f. Find the rider's speed vf at the bottom in terms of these variables.

Step 1: System and stages. System = rider + Earth. Start = top, end = bottom (h = 0 there). Friction is external and acts along the whole length L, so Wext = −fL.
Step 2: Energy equation.
½mvi² + mgh − fL = ½mvf²
Step 3: Solve for vf. Multiply every term by 2/m:
vf² = vi² + 2gh − 2fL/m
vf = √(vi² + 2gh − 2fL/m)
Step 4: Does it make sense? If f = 0, it becomes √(vi² + 2gh), the frictionless answer. Friction is subtracted, so it makes vf smaller. (R6 checks results like this in more depth.)
Step 5: Plug in. m = 60 kg, vi = 1.0 m/s, h = 8.0 m, L = 20 m, f = 90 N:
vf = √(1.0 + 2·9.8·8.0 − 2·90·20/60) = √97.8 = 9.89 m/s
Box D: ½mvi² + mgh − fL = ½mvf², so vf = √(vi² + 2gh − 2fL/m). With f = 0 it's the frictionless answer. Numbers: vf = 9.89 m/s.
