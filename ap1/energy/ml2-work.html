Work

About 12 minutes · Review for the Energy reassessment

In R1, energy crossed the system boundary as work. This lesson is about how to calculate that work, how to tell its sign, and how net work changes an object's kinetic energy.

Notes · Box A

Only the parallel part does work

A box slides 6.00 m to the right. You pull on it with a 50.0 N force. Drag the slider to change the angle θ between your force and the box's motion.

F∥ = F cos θ
W = F∥ d = Fd cos θ

Drag θ past 90° to see what happens. (Next unlocks once you do.)

Box A: Only the component of F parallel to the displacement does work:
W = Fd cos θ
• θ is the angle between F and d, whether you pull or push at an angle.
• Work is a scalar measured in joules: 1 J = 1 N·m.
• The perpendicular part of F does no work.

Box B: Work is positive when the force has a part along the motion, negative when it has a part against the motion, and zero when the force is perpendicular to the motion or nothing moves.

2. Friction on that same sliding box.

3. Gravity on a ball as it falls.

4. A librarian's hand holding a heavy book still for 20 s.

Notes · Box C

Net work changes kinetic energy

Add up the work done by every force on an object. That total, the net work, equals the change in its kinetic energy:

Wnet = ΔK = ½mvf² − ½mvi²
  • Wnet > 0: the object speeds up.
  • Wnet < 0: the object slows down.
  • Wnet = 0: the speed stays the same (even if some forces do work, they cancel).

K depends on v squared. Drag the speed of a 2.0 kg cart and watch K.

Try it. Go from 2 m/s to 4 m/s. When the speed doubles, K becomes…

Box C: Wnet = ΔK. Double the speed → 4× the K. Triple the speed → 9× the K. So stopping a car going twice as fast takes 4× the (negative) work.
Notes · Box D

Worked example

A 50.0 N force pulls an object at an angle of θ = 53.0° to its direction of motion. Its displacement is d = 6.00 m. How much work is done by the force on the object?

Step 1: Givens. F = 50.0 N, d = 6.00 m, and θ = 53.0°. The 53.0° is already the angle between F and d, so we can use it directly.
Step 2: The parallel part. Only the part of F along the motion pulls the box forward:
F∥ = F cos θ = (50.0 N)(cos 53.0°) = 30.1 N
Step 3: Work.
W = Fd cos θ = (50.0 N)(6.00 m)(cos 53.0°) = 181 J
Positive, because θ is less than 90°. Units: N·m = J.
Step 4: Does it make sense? Pulling straight along the motion (θ = 0°) would do (50.0)(6.00) = 300 J. Pulling at an angle wastes some of the force lifting up on the box, so 181 J (less than 300 J) is reasonable.
Step 5: Going further. Say the object is a 10.0 kg box that starts at rest on a frictionless floor. How fast is it moving after 6.00 m?
The normal force and gravity are perpendicular to d, so they do 0 J. The net work is just the 181 J from the pull:
Wnet = ½mvf² − 0
vf = √(2Wnet/m) = √(2·181/10.0) = 6.01 m/s
Box D: F∥ = 30.1 N, W = 181 J. Forces perpendicular to d do zero work, so Wnet = 181 J = ΔK, and vf = 6.01 m/s.
